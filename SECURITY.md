# Security Policy

## Reporting a Vulnerability

Please **don't open a public issue** for security problems. Instead, report them privately through GitHub's [private vulnerability reporting](https://github.com/cole-titze/nhl-odds/security/advisories/new) (the "Report a vulnerability" button on the repo's Security tab).

Include what you found, how to reproduce it, and which component it affects (web API, frontend, data collector, predictor, scheduler, or a container image).

This is a personal hobby project, so there's no formal SLA, but I'll aim to acknowledge reports within a week and keep you posted on the fix.

## Supported Versions

Only the latest `main` branch and the `:latest` container images published to `ghcr.io/cole-titze/nhl-odds/*` receive fixes.
